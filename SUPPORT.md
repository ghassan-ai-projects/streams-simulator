# Support

Streams Simulator is pre-release engineering software. Support is community and maintainer best-effort; no uptime or response-time commitment is made.

## Before asking for help

1. Read the [quickstart](documentation/getting-started/quickstart.md) and [limitations](documentation/limitations.md).
2. Run `go run ./cmd/streamsim help` and the relevant validation command.
3. Capture the exact commit, Go version, command, and error output.
4. For a run problem, include sanitized replay output and ledger classification.

## Where to ask

- Use the [repository issue tracker](https://github.com/ghassan-ai-projects/streams-simulator/issues) for reproducible bugs and documentation problems.
- Use [GitHub Discussions](https://github.com/ghassan-ai-projects/streams-simulator/discussions) for design questions and usage questions when that feature is enabled.
- Use the private path in [`SECURITY.md`](SECURITY.md) for suspected vulnerabilities.

Do not attach capability tokens, credentials, private receiver URLs, or sensitive domain data.
