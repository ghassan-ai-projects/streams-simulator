# Survey D: mcp, cli, score, audit, suite, refconsumer, cmd/streamsim (read-only)

Method: read every production file; grepped importers and symbol use (non-test). `go vet` on these packages is clean.
Confidence tags: [H] verified in code, [M] reasoned from code, [L] suspicion.

## 1. internal/mcp (23 files, ~1.5k lines)
**Today:** MCP tool wiring plus the whole director use-case layer plus world registry state. **Should own:** tool schemas, arg decoding, error-code mapping, resource handlers, operator capability gate. Use-case sequencing (run begin/end/score/verify/audit state machine) belongs in a layer below that mcp and cli can both call.
**Exported surface used outside the package (prod):** only `NewDirector`, `NewDirectorServer`, `NewOperatorServerResolver`, `(*Director).SetOperatorEndpoint`, and `ResolveOperator` through the `OperatorResolver` interface (cli/mcp.go:36-98). Everything else exported is used by tests or nobody: all `Director` verb methods (Advance, ApplyPerturb, ..., VerifyRun; only the handlers in-package call them), `WorldRecord`, `Director.{Catalog,Adapters,Worlds,Truth,OutDir}` fields (tests touch `.Worlds` 14x), `OperatorView` + `NewOperatorView` + `NewOperatorServer` (tests), `Nameplate*`, `EffectorInfo`, `EffectorInvoker`, `VerdictSink`, `ToolError`, `Code*`. `WorldRecord.Ended` (director.go:20) is never read or written [H]. `CodeProfileRateExceeded`, `CodeInterlockRefused`, `CodeNotImplemented` (errors.go:21,29,30) are never used [H].
**I/O / clock / global state:** `crypto/rand` for tokens (world.go:65-71, entropy edge); `d.OutDir` path join and `run.End`/`run.LoadArtifact` file I/O reached through run (run.go:95,148; world_commands.go:145); `context` stored in the struct (director.go:36, `d.ctx` used by CreateWorld and verifyArtifact); `sync.Mutex` only guards maps. No goroutines, no time, no env. Global: `implementation` var (server.go:11), `toolInputFactories` map (schemas.go:21).
**Mixed responsibilities (handlers are NOT all thin):**
- Run lifecycle rules live here: Started/RunEnded gating and "must seal before begin" (run.go:18-31, 33-47, 147-159), unblind refusal (run.go:88), non-reproducible detail string injected into the scorecard (run.go:170-172), default adapter literal `"native-jsonl"` (world_config.go:12; cli/run_options.go:46 repeats it), default sink/time-mode (world_config.go:31-41). These are run/world decisions, not protocol.
- `AuditScenario` (run.go:112-124) chooses audit policy (seed 1, 60e9 sample) and rebuilds entity ids (run.go:187-197); suite uses `Seed^0x5eed`, SampleNS 120e9 from cli/suite.go:22, setup+perturbations; so `sim.scenario.audit` and the suite admission disagree on the same injection [H]. It also passes setup=nil, perturbations=nil.
- `handleEntityRetire` (director_truth_handlers.go:35-44) is a use case inlined in a handler and sits in the truth file.
**Vocabulary / typing:** ~20 Director methods return `map[string]any` with stringly keys; tool names appear as literals in director_tools.go/operator_tools.go and again in schemas.go:21-49 and refconsumer/mcpclient.go. `Director.World()` returns the mutable record to callers. `toolDef` handler signature `(ctx, map[string]any)`. `num()/intArg` accept strings (arguments.go:43-45, `Sscanf` accepts "12abc") though the schema says integer; dead-ish permissiveness.
**Probable bugs / hazards (ranked):**
1. [H] Data race on `WorldRecord.Started`, `RunEnded` (run.go:29, 153; world_commands.go:144): written outside `d.mu`, read under it in runIsOpen (director.go:79-88). Check-then-set in BeginRun lets two concurrent `sim.run.begin` both pass. SDK dispatches calls concurrently.
2. [M] `advanceToolError` (world_commands.go:153-158) maps every non-quiescence error (ctx cancel, sink failure, run failed) to `clock_backwards`; misleading code on a test instrument.
3. [M] `sim.scenario.audit` with default `duration_ns` 0 gives 1 grid sample (audit/evidence.go:20) while the world runs 24h (audit/scenario_setup.go:65-72): degenerate verdict. See section 4.
4. [M] seed arrives as float64 from the SDK decode; `uint64(num(args,"seed",1))` (world_config.go:23) rounds seeds above 2^53 and wraps negatives; `DescribeWorld` returns `float64(seed)` (world_commands.go:20). Replay stays self-consistent, but the seed the caller asked for is not the seed used.
5. [M] `OperatorView.Report` (operator.go:144-157) applies `ReportQuiesced` before the verdict is validated; a rejected verdict still advances quiescence. `run_id` argument is accepted and ignored (operator_tools.go:68).
6. [L] `Invoke` swallows the invoker error into "the effector declined" (operator.go:136), so interlock refusal never maps to `CodeInterlockRefused`; token compared with `==` (operator.go:163, not constant time).
7. [H] DestroyWorld leaves `byRun` entries (world_commands.go:34-37) and a destroy racing a destroy can call `Run.End` twice.

## 2. internal/cli (17 files)
**Today:** flag parsing, wiring, and a good deal of use-case logic. **Should own:** flags, file discovery under `--*-dir`, process lifecycle (signals, listeners), printing; nothing else.
**Used outside:** `Main`, `Version`, `Commit` (cmd/streamsim/main.go:18-20). All else private.
**os/time/net sites (wiring vs decision):**
- Wiring (fine): signals/UDS (device.go:100-118), HTTP listener+goroutine (mcp.go:36-55), stdio session (mcp.go:101-110), directory reads (catalog.go:36, manifest.go:50-90), stdout/stderr printing (score.go:51, cli.go:56-70), file reads/writes (refconsumer.go:19,42; suite.go:51-56; score.go:24,38; device.go:63; device_world.go:15).
- Business decision or clock read in the edge: `timeNanos()` builds command ids `cli-<unixnano>` (arguments.go:36, run_script.go:70) which enter the recorded command log [H]; two scripted effectors in one tick would also collide on the idempotency key [L]. `deviceWorldPlant` builds the device clock from `time.Now()` (device_world.go:79-84). `releaseManifestIdentity` embeds `created_at` from time.Now and hard-coded policy (manifest_options.go:37-44). `cmdSuite` fixes `SampleNS: 120 * 1e9` (suite.go:22). `runReferenceConsumer` fixes MinConsecutive 3 / AbsenceFactor 3 (refconsumer.go:98-99) duplicating refconsumer.DefaultConfig.
**Mixed responsibilities:**
- Manifest policy and digest/signing sequence live in cli/manifest*.go: `{"consumer":{"name":"streamsim-refconsumer","version":"0.1.0"}}` and `{"suite":{"negative_class_fraction":0.4,"trivial_cutoff":0.9}}` are literals that duplicate refconsumer/verdict.go:20 + mcpclient.go:32, suite/generation_setup.go:25 and audit.BalancedAccuracyCutoff; they will drift silently [H].
- Artifact layout knowledge (`verdict.json`, `label.json`, `ledger.jsonl`, run.json beside it) is in cli/score.go:83-117 while run/finalize.go owns writing them. Offline scoring entry-point loads with plain `json.Unmarshal` (score.go:28) not `model.Decode` (UseNumber, trailing-data rejection), unlike the rest of the repo.
- Adapter directory loading (catalog.go:31-67) is reusable domain-input loading; mcp/cli duplicate `adapter list` projection (catalog.go:168-175 vs mcp/director_catalog_handlers.go:21-34, same map literal).
- `loadDomainSpec` (simulator_inputs.go:33) re-implements the first half of `loadSimulatorInputs`; `cmdSuite` loads the catalog separately.
**Bugs / hazards (ranked):**
1. [H] `streamsim verify` is not a verification: `cmdReplay(args, verifyOnly)` ignores `verifyOnly` (replay.go:12-22); `executeReplay`/`printReplayResult` (replay.go:37-52) print and return nil even when `matches=false`, so exit status is 0. Docs call verify "the explicit verification spelling used in scripts" (documentation/reference/cli.md:109). Changing exit status is a behaviour change: decide explicitly.
2. [H] Offline `streamsim score` cannot reproduce online scoring: it passes `calls=nil` (score.go:116), so Loop metrics are zero and `ActionFidelity` is false whenever the verdict has actions (score/actions.go:16: `len(used)==len(actions)`), while the online path computes both; scorecard `Reproducible/Unblinded` are never set offline though the artifact has them. The "online and offline MUST agree" contract (score/score.go:14-17) holds only in tests that pass calls explicitly (score/parity_test.go:36). The artifact dir has no effector-call log, so the data is simply not persisted.
3. [M] `cmd/streamsim/function_length.go` is a `//go:build ignore` dev tool inside the command directory (Makefile:109); not a product concern but belongs under tools/ or test/architecture.
4. [L] `fileSink.SubmitVerdict` (refconsumer.go:48-50) is an empty sink implemented in cli; `Runner` could treat a nil sink as "write nothing".

## 3. internal/score
**Today:** metric computation over a run's evidence. **Should own:** pure metrics over an evidence value; no knowledge of the run orchestrator.
**What it reads from `*run.Run`:** `ID`, `Verdict()`, `Ledger()`, `World.EffectorCalls()`, `AppliedPerturbations()`, `World.EmittedCount()`, `History()` (unexported `stateSnapshot` type, run/run.go:126), `Domain().Spec.Faults` (history.go:50-57), `Reproducible()`, `UnblindedStamp()` (score.go:90-101, consumer.go:9, instrument.go:8, judgment.go:8, loop.go:9-34, history.go:20-48). That is a plain data bundle; `Offline` already takes exactly that bundle minus history/faults.
**Exported surface used outside:** `Score` (mcp/run.go:166), `Offline` (cli/score.go:116), `Scorecard` (returned in JSON). `Metrics` structs and `Scorecard.Marshal` (history.go:59-66) are used by tests only [H]; `Marshal` sits in history.go oddly.
**I/O/clock/global:** none. Good.
**Mixed / drift:**
- `reasonOf`/`timingDeliveryReason` (instrument.go:12-34) hard-code 19 perturbation names as string literals; perturb exports constants and `Names`. A new perturbation compiles and silently scores `""` which can match ledger rows with empty reason [M].
- Online-only metrics (`Resolved`, `TimeToResolutionNS`, `DeadlineAdhered`; loop.go:13-19) need `History()` and faults; offline never computes them. Parity is therefore partial by construction.
- Magic policy numbers undocumented as constants: 30 min drop-match window (dropped_events.go:33), +60 s faulted sample and 0.5 recovery (loop.go:33,61,80).
- `commandsAppliedOnce` builds a throwaway `InstrumentMetrics` just to hold one bool (instrument_metrics.go:35-46); `consumer()` ignores its `gt` param.
**Dependency question:** score should depend on an evidence record, not on `run`. Candidate: a `score.Evidence` struct defined in score (verdict, ledger, calls, perturbations, emitted, history samples, faults, reproducible, unblinded, run id) and filled by a 10-line adapter in mcp/run.go (or a `(*Run).Evidence()` method in run). That removes score->run, makes `Score` and `Offline` one function, and gives parity by construction. No new package needed.

## 4. internal/audit
**Today:** builds two perturbed worlds, samples them, fits five hindsight detectors, grades. Pure compute plus world construction; no I/O. **Used outside:** `NewPanel`, `(*Panel).Audit`, `Verdict`, `Perturbation` (suite, mcp); `BalancedAccuracyCutoff` and `DetectorNames` only tests/within [H].
**Mixed:** `build` (scenario.go:26-40, scenario_setup.go) is world+perturb pipeline orchestration duplicated from run (without the adapter step, though the doc comment at audit.go:64-67 promises "adapter projection" [H]); `statistics.go`/`thresholds.go`/`detector.go` are pure fitting. `audit` imports `truth` only for `truth.SetupCall`, a plain data record (truth/solver.go:55); hosting it in model would let audit/suite stop importing truth for a struct.
**Hazards:**
1. [H] `injectAuditFaults` ranges over `map[string]int64` (scenario_setup.go:53-61); today the map has one key so order is fixed, but injection order into the world is a determinism hazard the moment a second fault is added. Replace with an ordered slice.
2. [M] `sampleEvidence` sizes the grid from `durationNS` (evidence.go:19-20) while `build` uses `auditHorizon` (24h cap, 24h when duration<=0, scenario_setup.go:65-72). Callers passing duration 0 (mcp/run.go:112, schema leaves it optional) get one sample.
3. [L] `p.fit` returns 0 for an unknown detector name (detector.go:44); `Audit` errors are prefixed "Audit:" (audit.go:72,76).
4. [L] `betterAccuracy` appends to `predictions` (detector.go:83); safe only because callers allocate len==cap.

## 5. internal/suite
**Today:** scenario generation, audit admission, composition accounting, command-log rendering. **Used outside:** `Generate`, `Config`, `Suite` (cli only). `Scenario`, `TrivialCase`, `Perturbation` only as fields of `Suite`.
**Mixed / drift:**
- Reimplemented stdlib: `indexOf`, `replaceAll`, `joinShortfalls` (entities.go:37-56, suite.go:83-92) and a local `min` shadowing the builtin (commands.go:70-75). `renderID` duplicates `world.RenderID`.
- Profile/policy literals in code: composition bounds 0.35/0.45, 10 %, 3 cascades, 10 pathology, and the profile names `"correlated_cascade"`, `"sensor_pathology"` (admission.go:30-55). Profile names are data; branching on them is exactly the per-domain-code smell AGENTS forbids [M]. Policy belongs in the profile (data) or one named policy struct.
- Perturbation parameter sampling by string name (commands.go:45-97) duplicates perturb parameter specs; if perturb adds a parameter, suite cannot discover it.
- `buildScenario` fabricates `audit.Verdict{Trivial:true}` for "no observable signal" (scenario.go:20-22): nil Scores/empty Best end up in `TrivialExcluded`; a missing-signal case is conflated with a trivial-baseline failure [M].
- `Suite.pickFault` has an unused receiver (scenario.go:91). RNG draw order depends on call order across `drawScenario`, `drawOnset`, `drawPerturbations` (scenario.go:53-65): fine, but any extraction must keep the draw sequence (negative -> fault -> entity -> onset -> perturbations).
**Determinism:** map iteration only in `orderedFaultWeights` (sorted); `uniformPositiveFault` sorts. No clock or env. Good.

## 6. internal/refconsumer
**Today:** reference detector + MCP operator client. **Should own:** detector over native-trace events and a client over the operator wire. **Used outside:** `New`, `Config`, `Nameplate`, `MCPOperator`, `NewMCPOperator`, `EffectorInvoker`, `VerdictSink` (cli); `DefaultConfig`, `QuiescenceReporter`, `ListEffectors`, `Runner.Process` partly only in tests [H: DefaultConfig and ListEffectors have no prod caller].
**I/O:** `context.Background()` hard-coded on every network call (mcpclient.go:33,62): not cancellable, violates ctx-first rule. No clock, env, goroutines.
**Mixed:** imports `world` only for `world.InvokeResult` (mcpclient.go:17, refconsumer.go:12): a consumer that models an external client depends on the simulator core. The wire result belongs in model. Hand-rolled `median` (insertion sort), `splitLines`, `splitKey`, `asFloat` (statistics.go) instead of slices/bytes/strings; refconsumer name/version literals duplicated (verdict.go:20, mcpclient.go:32, cli/manifest_options.go:41).
**Bugs:** [M] silence detections cite `seq:<s.lastSeq>` but `lastSeq` is set only in `detectConsecutive` (series.go:68), so a silence detection on an entity with no prior detection cites `seq:0` (series.go:102), which may be undelivered; score's `groundsEvidence` (score/evidence.go:9-19) then fails the consumer for an instrument-side bug. [L] `ListEffectors` decodes an array from structured content; MCP structured content should be an object (operator_tools.go:50 returns a bare slice); no prod caller so untested in the wild.

## 7. cmd/streamsim
`main.go` is correct and thin (version vars + `os.Exit(cli.Main(os.Args))`); Makefile:13 injects `main.Version/main.Commit`, then main copies to `cli.Version/Commit` (global mutable state in cli; acceptable, document). `function_length.go` is a dev tool (see 2.3).

## 8. Target shape (no new layers without a caller)
- `cmd` -> `cli` (flags, files, signals, printing only) -> use cases.
- mcp: keep as protocol adapter (schemas, tools, arg decode, error-code map, resources, operator gate). Move run lifecycle/registry decisions to a `director` use-case unit with typed results; the cheapest honest home is a non-exported-API file group in `internal/mcp` first (Round 4), promote to a package only if cli gets a second caller (e.g. `streamsim score` using the same scoring-evidence loader).
- score: `Evidence` struct in score; one scoring function; run adapter at the edge.
- perturb owns: delivery reason per perturbation + param spec (data next to `Names`); score and suite read it.
- model owns: `Perturbation` record, `SetupCall`, `InvokeResult` wire record (all plain data).
- edge adapters: `crypto/rand` token, `time.Now` via one function, file writes in cli.

## 9. Refactor rounds (small, ordered). Each keeps behaviour; guard = test that proves it
1. **Dead surface + unexported surface (mcp, refconsumer).** Delete `WorldRecord.Ended`, unused `Code*`, unexport Director verb methods/fields no prod caller uses (tests: switch to handlers or `export_test.go`). Guard: `go build ./...`, existing mcp e2e tests, `test/architecture`. Hazard: tests that touch `.Worlds` (14 sites).
2. **Vocabulary dedup, no behaviour change.** suite uses `world.RenderID`, builtin `min`, `strings.Join`; score uses `perturb` constants via a perturb-owned reason table; shared `Perturbation`/`SetupCall` in model. Guard: new test iterating `perturb.Names` asserting the reason table equals what perturb actually emits; suite golden test: `Generate` JSON for fixed cfg byte-equal before/after (RNG order!). Hazard: allowed-import list update.
3. **Score evidence value.** Introduce `score.Evidence`, make `Score` and `Offline` share one path; keep `Scorecard` JSON byte-identical. Guard: existing `parity_test.go` and `shared_policy_test.go`; add golden scorecard JSON for one run. Hazard: `Scorecard.Reproducible/Unblinded` and omitempty fields must not change; `nil` vs empty ledger/calls semantic (consumer.go:18-20, offline.go:15-20).
4. **mcp lifecycle under lock.** Fix the Started/RunEnded race (guard transitions with `d.mu` or per-world mutex) while keeping error precedence: unknown world -> already open -> sealed check (run.go:18-31). Guard: `go test -race` concurrency test that issues two `run.begin`; table test of codes. Hazard: do not hold `d.mu` across `Run.End`/`Advance` (blocking quiescence waits).
5. **cli use-case extraction.** Move manifest build/sign and artifact-layout loading behind named functions that take injected `now`/readers; cmdSuite calls `suite` defaults instead of literals; share `audit` policy constants (60 s, 120 s) as named constants. Guard: golden manifest with fixed `created_at`; `streamsim suite` byte-equal output for a seeded run. Hazard: ed25519 signs sha256 of canonical body (manifest.go:43), key bytes must not change.
6. **Intentional corrections, each as its own commit with regression test (not in refactor commits):** (a) `verify` non-zero on mismatch; (b) offline score parity (needs persisted effector log or explicit "partial" marker); (c) ordered fault injection slice in audit; (d) audit grid length from horizon; (e) deterministic `cli-<index>` command ids; (f) silence-detection evidence ref; (g) advance error mapping. Each changes observable bytes/exit codes; record in docs/refactoring evidence.
