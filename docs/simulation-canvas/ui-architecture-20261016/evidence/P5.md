# Phase 5 evidence — feature module boundaries and CSS ownership

- **Scope:** [PLAN.md](../PLAN.md) §5 Phase 5 against [README.md](../README.md) §3.2–3.4 and F4.
- **Status:** in progress. The graph CSS partition and the first module extractions are committed by an earlier round;
  the remaining feature moves, the primitives and the stylesheet dissolution are being completed now.

## Delivered so far

- `model/workspace` (contract + facade over `internal/`), `app/session` (contract + facade, pairing code moved into
  `app/session/internal/sessionCode.ts`), `ui/primitives` (facade), `app/shared` (operation identity), `app/ports`
  (foundation), `model/graph` and `ui/graph`.
- `canvas/ARCHITECTURE.md` is generated from `canvas/architecture.json` by `scripts/write-architecture-doc.ts` and
  checked by `npm run architecture`, so the human table and the machine register cannot drift.
- The register's `callers` field is derived: `scripts/sync-callers.ts --check` fails when a module's recorded callers no
  longer match the import graph, and `--write` repairs them.
- Graph CSS split by responsibility (committed earlier): nodes, pins, frame, readout and marks sheets, the React Flow
  hooks and the minimap override in a registered `vendor.module.css`, and the zoom-tier contract expressed as local
  classes with `data-zoom-tier` on the graph root.

## Tooling built for this phase (in `canvas/scripts/`)

- `codemod-imports.ts` — AST import/export rewriter: rewrites relative specifiers through a move map, routes imports
  that come from outside a module to that module's entrypoint, and is dry-run by default (`--apply` writes).
  Validated end to end on a throwaway probe (move + rewrite of a value import and a type import).
- `draft-facades.ts` — computes, from the import graph, exactly which names each module's callers need, and writes
  `contract.ts` (public types) and `index.ts` (values + contract) per module.
- `sync-callers.ts` — derives and checks the register's `callers`.
- `write-architecture-doc.ts` — generates `ARCHITECTURE.md` from the register and checks it.
