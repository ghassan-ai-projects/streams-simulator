# Phase 1 evidence — graph extraction

- **Scope:** extract the shared graph into `model/graph` and `ui/graph`, preserve graph behavior and emitted stylesheet behavior, and remove graph-owned cross-feature edges.
- **Outcome:** source work and independent reviews are complete; **validation is pending**. The user directed the team to finish the production migration before repairing/rerunning remaining tests and gates. This evidence does not claim the Phase 1 exit or all-gates-green.

## Delivered shape

- `model/graph` owns graph projection, layout, wire routing, outline projection, and stable graph contracts. Its facade exports the graph values/types currently named by callers. Plant presentation uses `routeView` and `ViewPresentation`; graph model contracts are in `model/graph/contract.ts`.
- `ui/graph` owns graph controls, outline, nodes, edges, viewport behavior, and graph CSS. Its public contract is in `ui/graph/contract.ts`; feature screens import through `ui/graph/index.ts`.
- The launch/review presentation choices are named `pins`/`rows`; graph interaction choices are `inspect`/`connect`, replacing graph-specific boolean choices.
- The outline projection moved from `ui/plant/Outline.tsx` to `model/graph/internal/outline.ts`. Its filtering, hall visibility, populated-first ordering, empty-area behavior, issue marks, and descendant counts were compared with the prior implementation.
- Graph-owned CSS moved to `ui/graph/internal/graph.module.css`; remaining `PlantScreen.module.css` rules serve editor/run screen layout and inspector presentation. React Flow vendor selectors are scoped in `vendor.module.css` and applied to the actual handle and minimap elements.
- The graph module pair is registered in `canvas/architecture.json`. Remaining editor/run screen-layout CSS imports are Phase 5 debt.

## Review corrections

The behavior review found that moving React Flow vendor selectors into a CSS module changes their generated local class names. Without applying those classes to the React Flow elements, the selectors no longer match. The current source applies `vendor.dot` to handles and `vendor.minimap` to the minimap. The failing-first browser check observed `position: absolute` where the minimap requires `static`; those vendor-class changes were restored after that run. A positive browser rerun remains pending.

The architecture review found gaps in facade type-only re-export checks and overly broad ratchet path-move matching. Those checks now reject internal type leaks and unrelated/cross-layer moves; vendor CSS allowances are finite and checked. Focused fixtures and checker checks passed. Full review details are in [P1 review](../reviews/P1.md).
