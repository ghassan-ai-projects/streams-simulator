## 2. What the reviewers verified independently

- The register was exhaustive: with the debt list emptied in a copy, the checker printed 47 violations in seven rule
  groups, exactly matching the 47 entries by (rule, file, target); every cap equals the file it caps, every allowance
  equals its `:global`/`!important` count, and the single colour exception equals its literal count.
- Every implemented rule was mutation-tested: deleting one rule call at a time from `check()` broke at least one fixture
  for all 16 rule functions that existed at the time.
- The emitted-stylesheet baseline was recounted from the built CSS (34 `!important`, 17 `z-index`, 33 positioned) and
  the sentinels are in increasing order.
- The gate chain contains `npm run architecture` and `npm run css:emitted`; `Makefile`'s `canvas-check` runs them under
  `npm ci`; `git diff HEAD -- Makefile scripts test/architecture governance .github` is empty, so `make gate-ratchet` and
  the root `scripts/` are untouched.
- The lifecycle regressions were re-run against the pre-change stores: nine fail (six in the batch transcript plus the
  two plant/editor cases and the post-close refresh with a discriminating report); three are green guards and are
  labelled as such in the evidence.
- Coverage after the change: adapters 76.7 %, app 97.8 %, model 98.4 % statements, floors held.
