Controls

Focus is a 2 px accent ring with 2 px offset. Disabled is 50 %, stays focusable (aria-disabled) and shows its reason inline. Read only is a dashed border with a lock.

Nodes

Build mode tints the header by category. Run and Review use a neutral header with a 3 px category stripe, so only alarms and faults draw the eye.

Pins

Shape names the family (○ flow, □ energy, ◇ state and signals); colour names the type; the legend and every tooltip name it in words.

Wires

Dimmed wires keep at least 3:1 against the canvas. A selected wire is 3.2 px with an accent halo; Delete removes it.

Compile button

Status chips

Red is only alarms and faults (and, in Build and Pairing, an error that blocks the next step), amber only warnings and stopped equipment, purple only truth and Explore, accent blue only selection, focus and the primary action. Every chip carries an icon and a word.

Port-type legend

Nine colours for the 19 library port types. The canvas maps each library type to one colour; the tooltip shows the exact type.

Single-letter keys (C, A) act only while the graph has focus. The Outline tree and the Details Ports table are the non-graph way to wire: every port lists its connections and a Connect… menu of compatible ports. Compile results and new alarms are announced through a polite live region. Animations stop under prefers-reduced-motion. Full-tier pin rows are 24 px; the compact tier shows readings only and is not wired — zoom in or use Details.
