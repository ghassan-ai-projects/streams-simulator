## 3. The feeder (not preserved from September; rebuilt from the events in the September `stream.db`)

September's 61 events: 12 ticks x 5 types (`temp`, `humidity`, `ambient`, `fan_tach`, `heartbeat`), 30 s apart in event time, back-dated so the last
tick is about 2 s old, sent 100 ms apart; temp 31 + 0.48 per tick (31.0 to 36.28), humidity 48, ambient 20, rpm 0; seq 1..60. Then, about 21 s later,
one extra heartbeat (seq 100, event time = now); the decision came 100 ms after it (scheduler debounce and cooldown use the wall clock).
The script reproduces this. Offline check on 2026-10-20: `agentic-stream run` on its burst gave 60 events, 0 quarantined, phases candidate, watch, cooling.

```bash
cat > "$RUN/feed_telemetry.py" <<'PY'
#!/usr/bin/env python3
"""usage: feed_telemetry.py SOCKET TAG [KICK_AFTER_S] | SOCKET TAG --kick SEQ | --dump TAG"""
import json, socket, sys, time
from datetime import datetime, timedelta, timezone
TICKS, STEP_S = 12, 30
def stamp(t): return t.astimezone(timezone.utc).strftime("%Y-%m-%dT%H:%M:%S.%fZ")
def envelope(tag, name, seq, event_time, data):
    data = {"boot_id": "boot-A", "quality": "valid", "seq": seq, **data}
    return json.dumps({"id": f"p05-{tag}-{name}-{seq}", "type": f"zone.{name}.observed", "schema_version": "1.0",
        "tenant_id": "default", "source": f"simulator-{tag}", "partition_key": "zone-01",
        "entity": {"type": "thermal_zone", "id": "zone-01"}, "event_time": stamp(event_time),
        "ingested_at": stamp(datetime.now(timezone.utc)), "classification": "internal", "data": data})
def tick(tag, i, base):
    t, mono = base + timedelta(seconds=STEP_S * i), 1_000_000 + STEP_S * 1_000_000 * i
    rows = [("temp", {"celsius": round(31 + 0.48 * i, 2), "device_mono_us": mono}), ("humidity", {"percent": 48, "device_mono_us": mono}),
            ("ambient", {"celsius": 20, "device_mono_us": mono}), ("fan_tach", {"rpm": 0, "device_mono_us": mono}), ("heartbeat", {})]
    return [envelope(tag, n, 5 * i + k + 1, t, d) for k, (n, d) in enumerate(rows)]
def start_base(): return datetime.now(timezone.utc) - timedelta(seconds=STEP_S * (TICKS - 1) + 2)
def send(c, lines): c.sendall(("\n".join(lines) + "\n").encode())
def connect(path):
    c = socket.socket(socket.AF_UNIX); c.connect(path); return c
a = sys.argv[1:]
if len(a) == 2 and a[0] == "--dump":
    base = start_base(); print("\n".join(l for i in range(TICKS) for l in tick(a[1], i, base)))
elif len(a) == 4 and a[2] == "--kick":
    send(connect(a[0]), [envelope(a[1], "heartbeat", int(a[3]), datetime.now(timezone.utc), {})])
elif len(a) in (2, 3):
    c, base = connect(a[0]), start_base()
    for i in range(TICKS): send(c, tick(a[1], i, base)); time.sleep(0.1)
    print("burst sent: 60 events", flush=True); time.sleep(float(a[2]) if len(a) == 3 else 25)
    send(c, [envelope(a[1], "heartbeat", 100, datetime.now(timezone.utc), {})]); print("kick sent", flush=True); time.sleep(1)
else: sys.exit(__doc__)
PY
python3 "$RUN/feed_telemetry.py" "$RUN/telemetry.sock" r1 25 | tee "$RUN/feed.log"
```

If the decision does not appear within about 60 s, send another heartbeat: `python3 "$RUN/feed_telemetry.py" "$RUN/telemetry.sock" r1 --kick 101` (then 102, ...).
Envelope fields and the five event types are those of the spec inputs and `internal/spec/internal/domain/event_schema_data.json` (`zone.{temp,humidity,ambient,fan_tach,heartbeat}.observed`, schema 1.0).
